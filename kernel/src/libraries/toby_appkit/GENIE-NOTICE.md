Genie effect attribution and license
====================================

The integer-only Genie transform in `src/genie.rs` is a clean `no_std`
implementation of the publicly described geometry in Harshil Shah's
"Recreating the macOS Genie Effect", with an earlier visual reference in the
SwiftUI/Metal demonstration `genie-main`. Neither project's source code or
shader is copied into AppKit or Kira. Apple's WindowServer implementation is
private and is not reproduced from its source.
